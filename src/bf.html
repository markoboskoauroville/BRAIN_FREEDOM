Keys

Point at any file. Notes, exports, a mess, it does not matter. Every key inside is found, sorted by provider and queued. Transcription walks the queue until one answers, so a dead key costs you a second rather than a session. Shape is only used to sort, never to reject, because providers change their formats without telling anybody.

Browser

Brain Freedom opens itself in the browser you pick here, ignoring whatever macOS thinks the default is. Firefox is chosen first when it is present, because its recorder produces Opus, which is the right format for speech.
