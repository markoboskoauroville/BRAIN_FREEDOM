Keys

Point at any file. Notes, exports, a mess, it does not matter. Every key inside is found, sorted by provider and queued. Transcription walks the queue until one answers, so a dead key costs a second rather than a session. Shape only sorts a key, it never rejects one.

Voice

Reading aloud uses edge-tts, which returns the timing of every word, so the highlight follows the speech exactly rather than guessing.

Browser
